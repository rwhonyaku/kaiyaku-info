# AGENTS.md — kaiyaku-info.com

## Project Identity (LOCKED)
This is a Japan-focused informational reference site.

Purpose:
Organize officially published cancellation / withdrawal procedures into clear, structured, neutral reference pages.

Monetization:
Display ads only (Google AdSense). No affiliate links, no lead generation, no email capture.

---

## Non-Negotiable Rules

### Content Rules
- Only summarize officially published information
- No advice, no recommendations, no opinions
- No “best”, “easy”, “should”, “recommended”
- No user-generated content
- No comparisons or rankings
- Always include reference date
- Always include official links

---

### What MUST be improved
The site must NOT appear:
- templated
- thin
- AI-generated
- purely paraphrased

The site MUST:
- feel human-curated
- feel structured and intentional
- demonstrate clear editorial effort
- improve readability and scannability
- organize information better than official sources

---

### Allowed Enhancements
WITHOUT breaking neutrality:
- Improve layout hierarchy
- Improve typography and spacing
- Add structured sections
- Add clarity about where/how cancellation occurs (if official)
- Add context framing (what this page covers)
- Improve tables
- Improve headings
- Improve visual grouping
- Improve internal linking

---

### Forbidden Enhancements
- No adding opinions
- No adding personal advice
- No adding speculation
- No adding filler text
- No fake FAQs
- No “SEO fluff”

---

## Technical Rules

- Use Next.js App Router
- Keep flat structure: /service/{slug}
- Maintain static generation
- Do not introduce unnecessary complexity
- No heavy libraries unless justified

---

## Design Direction

Target:
Modern, clean, minimal, high-trust Japanese UI

Avoid:
- “government document” feel
- overly dense text blocks
- generic template look

Prioritize:
- whitespace
- readable typography
- section separation
- subtle visual hierarchy

---

## Objective

Increase:
- perceived content value
- trust
- readability
- dwell time
- AdSense approval probability

WITHOUT changing:
- core content meaning
- neutrality
- source integrity
